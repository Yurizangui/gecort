What GECORT does

GECORT is a private tool run by the channel “Bungle Bangle da Banda”. It turns episodes of podcasts that have authorized us into short and long video clips, adds subtitles, and publishes them to our own YouTube and TikTok accounts using the official APIs (YouTube Data API and TikTok Content Posting API).

  • Only the channel operator uses the tool, and it only posts to the operator’s own accounts.
  • Every clip credits the original podcast.
  • Creators can ask for any clip to be removed.
